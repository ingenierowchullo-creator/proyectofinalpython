# Sistema de Gestión de Biblioteca en Python

## Descripción

Proyecto final del curso Fundamentos de Programación.

Permite:

- Registrar libros
- Mostrar libros
- Buscar libros
- Modificar libros
- Eliminar libros
- Registrar préstamos
- Registrar devoluciones
- Mostrar estadísticas
- Guardar información en archivos

## Tecnologías

- Python 3

## Archivos

- main.py
- biblioteca.py
- biblioteca.txt
